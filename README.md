# SOC-2-Control-Mapping-and-Gap-Analysis-Matrix
A SOC 2 Control Mapping and Gap Analysis Matrix featuring a control alignment spreadsheet with mock company evidence artifacts
The mock company being used here is: TacoTrax a software designed for taco truck owners to use in order to sell, order, collect customers data for future purchases.
## Repository Structure
- `soc-2-matrix.csv`: The main compliance mapping and gap analysis spreadsheet.
- `/SOC-2-Artifact/`: Folder containing sample evidence and policies.
